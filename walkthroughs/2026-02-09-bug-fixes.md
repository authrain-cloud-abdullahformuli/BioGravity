## Changes Made

### Bug #1: Theme Toggle Not Working

**File**: [ThreeBackground.tsx](../src/components/landing/ThreeBackground.tsx)

**Problem**: The 3D background used `theme` property which can be undefined during SSR, and the Canvas didn't have explicit background colors.

**Solution**:

- Changed from `theme` to `resolvedTheme` which resolves the actual theme value
- Added `mounted` state to prevent hydration mismatch
- Set explicit background colors for Canvas (`#030712` dark, `#f8fafc` light)
- Added `<color attach="background">` element to three.js scene

### Bug #2: Project Dialog Not Closing

**File**: [new-project-dialog.tsx](../src/components/dashboard/new-project-dialog.tsx)

**Problem**: `router.refresh()` was racing with `setOpen(false)`, causing the page to re-render before the dialog state could propagate.

**Solution**:

- Added 150ms delay before calling `router.refresh()`
- Moved `setFormData` reset before the delayed refresh

render_diffs(src/components/dashboard/new-project-dialog.tsx)

---

### Bug #3: 3D Graph Causes Browser Timeouts

**File**: [graph-scene.tsx](../src/components/graph/graph-scene.tsx)

**Problem**: Heavy 3D initialization was blocking the main thread, causing browser connection resets.

**Solution**:

- Added `isReady` state with deferred initialization via `requestAnimationFrame`
- Added loading spinner displayed during initialization
- Added performance props: `cooldownTicks={100}`, `warmupTicks={50}`, `d3VelocityDecay={0.4}`
